# lib-seat-system

A desktop-based study room seat reservation and management system.

* **Core Framework**：Spring Boot 3.2.5
* **Graphical Interface**：JavaFX 21
* **Persistence Layer**：Spring Data JPA
* **Database**：SQLite
* **Build Tool**：Maven


## Prerequisites
* **Java Development Kit (JDK)**: Version 21
* **Apache Maven**: Version 3.8+

## Usage

```bash
mvn javafx:run
